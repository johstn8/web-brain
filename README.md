# Web-Brain

KI-orientiertes Obsidian-Brain für professionelle Websites mit Schwerpunkt Frontend und Design.

Start: [[00-start/00-brain-index.md]]

Verbindlicher Ablauf: [[00-start/05-web-product-workflow.md]]. Jeder Umsetzungsauftrag erzeugt vor Recherche oder Code einen eigenen Ordner unter `../projekte/<Projektname>/` mit `PROJECT.md`, `SOURCE-RIGHTS-REVIEW.md`, `ASSET-REGISTER.md`, `DATA-PROCESSING-INVENTORY.md`, einem fortlaufenden `release-readiness/<website-slug>.md` je Website und der Pflichtstruktur aus [[60-operations/delivery-and-local-start.md]].

**Die Anzahl der Websites steht im Auftrag.** Ohne Angabe wird genau eine Website gebaut, mit genannter Zahl genau diese Anzahl. Jede gebaute Website ist vollständig: echte Unterseiten, ein zweckbezogenes Motion-Budget und vollständiges SEO. Auf `217.154.218.30` erfolgt der Zugriff über `johannstein.com` ohne festen Projektport, auf anderen Rechnern über den dokumentierten lokalen Port.

**Bei jedem Website-Build wird der UI UX Pro Max Skill stark empfohlen**, ist aber keine Abnahmebedingung; Gate `G1` prüft das Ergebnis, nicht das Werkzeug. Der Leitbenchmark für Aussehen und Bedienung kommt aus [[20-design/interface-benchmarks.md]]. Die H0-Handwerksuntergrenze gilt immer; konkrete Stile bleiben wählbar. Informationsmenge und Textlänge folgen [[10-strategy/information-density-and-mobile-clarity.md]], Bildbeschaffung und KI-Bildbearbeitung folgen [[20-design/imagery-and-ai-editing.md]]. Das zentrale Owner-Hosting steht in [[60-operations/owner-hosting-interface.md]], der je Website gelieferte Datenvertrag in [[80-templates/owner-hosting-website-contract.md]], die Produktionsreife in [[60-operations/release-readiness-register.md]].

Bilder, Designs, Animationen und weitere Assets werden direkt eingesetzt; Quelle und tatsächlicher Einsatz werden danach nur für die spätere Owner-Einschätzung dokumentiert. Ein gefundenes Firmenlogo wird immer sichtbar verwendet. Bei Neubau einer alten Website zusätzlich [[10-strategy/existing-website-rebuild.md]] ausführen.

Die ursprüngliche Sammlung bleibt lokal als nicht versionierte `TasksForAgent.md` ein Herkunftsnachweis, ist aber leer und nicht kanonisch.
