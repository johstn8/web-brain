# Web-Brain

KI-orientiertes Obsidian-Brain für professionelle Websites mit Schwerpunkt Frontend und Design.

Start: [[00-Start/00 Brain Index]]

Verbindlicher Ablauf: [[00-Start/05 Web Product Workflow]]. Jeder Umsetzungsauftrag erzeugt vor Recherche oder Code einen eigenen Ordner unter `../projekte/<Projektname>/` mit `PROJECT.md`, `SOURCE-RIGHTS-REVIEW.md`, `ASSET-REGISTER.md`, `DATA-PROCESSING-INVENTORY.md` und der Pflichtstruktur aus [[60-Operations/Delivery and Local Start]].

**Die Anzahl der Websites steht im Auftrag.** Ohne Angabe wird genau eine Website gebaut, mit genannter Zahl genau diese Anzahl. Jede gebaute Website ist vollständig: echte Unterseiten, hohe Scroll-Choreografie und vollständiges SEO. Auf `217.154.218.30` erfolgt der Zugriff über `johannstein.com` ohne festen Projektport, auf anderen Rechnern über den dokumentierten lokalen Port.

**Bei jedem Website-Build wird der UI UX Pro Max Skill ausgeführt, ausnahmslos.** Der Leitbenchmark für Aussehen und Bedienung kommt aus [[20-Design/Interface Benchmarks]]. Die H0-Handwerksuntergrenze gilt immer; B5 ist ein wählbares Stilprofil. Informationsmenge und Textlänge folgen [[10-Strategy/Information Density and Mobile Clarity]], Bildbeschaffung und KI-Bildbearbeitung folgen [[20-Design/Imagery and AI Editing]]. Das zentrale Owner-Hosting steht in [[60-Operations/Owner Hosting and Dashboard]], der je Website gelieferte Datenvertrag in [[80-Templates/Owner Hosting Website Contract]].

Bilder, Designs, Animationen und weitere Assets werden direkt eingesetzt; Quelle und tatsächlicher Einsatz werden danach nur für die spätere Owner-Einschätzung dokumentiert. Ein gefundenes Firmenlogo wird immer sichtbar verwendet. Bei Neubau einer alten Website zusätzlich [[10-Strategy/Existing Website Rebuild]] ausführen.

Die ursprüngliche Sammlung bleibt lokal als nicht versionierte `TasksForAgent.md` ein Herkunftsnachweis, ist aber leer und nicht kanonisch.
