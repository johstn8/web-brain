# Web-Brain

KI-orientiertes Obsidian-Brain für professionelle Websites mit Schwerpunkt Frontend und Design.

Start: [[00-Start/00 Brain Index]]

Verbindlicher Ablauf: [[00-Start/05 Web Product Workflow]]. Jeder Umsetzungsauftrag erzeugt vor Recherche oder Code einen eigenen Ordner unter `../projekte/<Projektname>/` mit `PROJECT.md`, `SOURCE-RIGHTS-REVIEW.md`, `ASSET-REGISTER.md`, `DATA-PROCESSING-INVENTORY.md` und der Pflichtstruktur aus [[60-Operations/Delivery and Local Start]].

**Die Anzahl der Websites steht im Auftrag.** Ohne Angabe wird genau eine Website gebaut, mit genannter Zahl genau diese Anzahl. Jede gebaute Website ist vollständig: echte Unterseiten, hohe Scroll-Choreografie, vollständiges SEO und ein eigener fester Port.

**Bei jedem Website-Build wird der UI UX Pro Max Skill ausgeführt, ausnahmslos.** Der Leitbenchmark für Aussehen und Bedienung kommt aus [[20-Design/Interface Benchmarks]]. Informationsmenge und Textlänge folgen [[10-Strategy/Information Density and Mobile Clarity]], Bildbeschaffung und KI-Bildbearbeitung folgen [[20-Design/Imagery and AI Editing]].

Bilder, Designs, Animationen und weitere Assets werden direkt eingesetzt; Quelle und tatsächlicher Einsatz werden danach nur für die spätere Owner-Einschätzung dokumentiert. Ein gefundenes Firmenlogo wird immer sichtbar verwendet. Bei Neubau einer alten Website zusätzlich [[10-Strategy/Existing Website Rebuild]] ausführen.

Die ursprüngliche Sammlung bleibt als [[TasksForAgent]] als Herkunftsnachweis erhalten, ist aber leer und nicht kanonisch.
